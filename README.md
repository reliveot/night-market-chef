# 《台灣夜市料理秀》（Taiwan Night Market Chef）V1.1

一款專為中風後上肢動作控制、方向判斷與認知訓練設計的網頁互動式復健遊戲（亦適合一般民眾體驗）。採用純前端 HTML / CSS / JavaScript 開發，可直接部署至 GitHub Pages。

## 核心特色
1. **30 道台灣夜市經典美食**：涵蓋煎台、油炸、炭烤、熱食與湯品、甜點與飲料五大分類；每道固定五題（前四題四種食材隨機排列、第五題固定出餐）。
2. **臨床友善動作判定**：
   - **非固定起點與慢速相容**：無需回到中央、無需碰觸特定物件、不限移動速度，配合手掌中心質心追蹤與 One Euro Filter 抗抖動濾波。
   - **四方向／八方向 & 正方向／全部反方向／正反混合**：採高對比色區分（照箭頭為暖金黃色、反方向為青藍色）。
   - **等待挑戰**：手部於容許範圍內穩定維持 3 秒（含 400ms 瞬跳寬限）。
   - **自由翻炒**：不限方向累積移動軌跡（採「參考點滑動法」確保慢速移動也能累積，預設個人化校正幅度 5 倍，可調 3／5／8 倍）。
3. **雙操作模式**：支援前鏡頭手部追蹤（15 FPS / 10 FPS 省電順暢模式與離屏 256×192 推論）與觸控／滑鼠拖曳操作。
4. **30 道美食收集圖鑑與延伸資源**：使用 `localStorage` 記錄收集進度，並於設定頁底部完整保留《吱吱復健》衛教、線上課程與 3D 列印手部練習工具資源。

## 部署至 GitHub Pages
1. 在 GitHub 建立新的 Public Repository（例如 `taiwan-night-market-chef`）。
2. 將本資料夾內所有檔案（`index.html`、`css/`、`js/`、`assets/`、`README.md`）上傳至 Repository 根目錄。
3. 前往 **Settings > Pages**，將 Source 設為 `Deploy from a branch`，分支選擇 `main` / `/ (root)` 並儲存。
4. 數分鐘後即可透過 `https://<你的帳號>.github.io/taiwan-night-market-chef/` 開啟使用（攝影機功能需在 HTTPS 環境下運作，GitHub Pages 預設支援 HTTPS）。
