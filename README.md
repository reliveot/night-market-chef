# 《台灣夜市料理秀》（Taiwan Night Market Chef）V2.0 體感大型機台版

一款專為中風後上肢動作控制、方向判斷、反應抑制與認知推理訓練設計的網頁互動式體感復健遊戲（亦適合一般民眾體驗）。採用純前端 HTML / CSS / JavaScript 開發，可直接部署至 GitHub Pages。

## V2.0 核心升級特色
1. **滿版全螢幕體感大型機台介面 (`100dvh`)**：
   - 進入遊戲即以玩家即時鏡像畫面為全螢幕背景（含微暗暖色燈籠遮罩確保前景 100% 清晰），手部位置直接渲染發光游標與動態光軌，無需角落小鏡頭窗。
   - 細緻半透明 3D 發光方向箭頭直接疊加於中央超大食材正上方（正方向為暖金黃色、反方向為青藍色），不遮擋食材細節。
   - 極簡懸浮夜市紅燈籠 HUD（無暫停鈕干擾），底部配置 4 格食材收集槽與本局已出餐縮圖列。
2. **50 道台灣夜市手繪水彩美食 & 94 種獨立食材圖庫**：
   - 涵蓋「煎台料理」、「油炸料理」、「炭烤料理」、「熱食與湯品」、「甜點與飲料」五大分類各 10 道（共 50 道），全數採用**台灣懷舊暖色手繪水彩風** 512×512 透明底 WebP 圖檔。
3. **四大烹飪手感完成動畫（操作相同，視覺回饋各異）**：
   - `🔪 切菜刀法`：光刃斜切過食材，食材切開成兩半並飛入收集槽。
   - `🧂 撒粉／淋醬`：不切半，灑出金色粉塵星雨與香氣提味光暈。
   - `🥣 倒料／下鍋`：不切半，呈現傾倒波紋與水花粒子。
   - `🔥 翻面／夾取`：不切半，食材 360° 翻面跳躍並冒出焦香鍋氣。
4. **進階動作與反應抑制題型**：
   - **🦠 壞食材抑制控制 (Go / No-Go)**：隨機出現發霉與繞飛小蒼蠅之壞食材，玩家需忍住不揮動 2.5 秒將其自動掃進垃圾桶。
   - **⚔️ 兩刀連擊 (Double-Cut)**：大塊食材需連續揮動兩刀（支援第一刀正面金黃＋第二刀反面青藍）。
   - **🔥 自由翻炒（僅主動移動時震動）**：參考點滑動法累積任意方向移動距離，僅在手部主動翻炒時觸發鐵鍋震動，滿格後拋鍋爆香出餐。
5. **兩大訓練模式 & 三種挑戰規則**：
   - **💪 動作料理模式**：第 1–4 步備料、第 5 步大火翻炒或盛盤動作出餐。
   - **🧠 認知推理選菜模式**：第 1–4 步隱藏料理名稱（`❓ 神秘料理`），第 5 步依底部 4 樣食材線索，以手部游標移動懸停 0.8 秒從 **2 選 1（左右）／3 選 1（左上右）／4 選 1（上下左右）** 中選出正確料理。
   - **三種挑戰規則**：支援「指定道數（1/2/3/5/10 道）」、「限時出餐（30/60/90/120 秒）」與「🏮 夜市無盡營業模式（累積銅板營業額與攤位星等稱號）」。
6. **50 道美食收集圖鑑與延伸資源**：
   - 使用 `localStorage` 記錄 50 道美食收集進度，並於設定頁底部完整保留《吱吱復健》衛教、線上課程與 3D 列印手部練習工具資源。

## 部署至 GitHub Pages
1. 在 GitHub 建立或更新 Public Repository（例如 `taiwan-night-market-chef`）。
2. 將本資料夾內所有檔案（`index.html`、`css/`、`js/`、`assets/`、`README.md`）上傳至 Repository 根目錄。
3. 前往 **Settings > Pages**，將 Source 設為 `Deploy from a branch`，分支選擇 `main` / `/ (root)` 並儲存。
4. 數分鐘後即可透過 `https://<你的帳號>.github.io/taiwan-night-market-chef/` 開啟使用。
